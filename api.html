⚡ MOSKO CHEATS API

لوحة اختبار API لمفاتيح MOSKO. هذه الواجهة لا تستبدل السيرفر الخلفي.

الحالة: لم يتم الاتصال بأي سيرفر بعد.

1. إعداد رابط API

اختبار GET فقط. نجاحه لا يثبت أن السيرفر يدعم إضافة المفاتيح أو التحقق منها.

2. إضافة مفتاح إلى السيرفر

سيُرسل POST بصيغة JSON. يجب أن يدعم السيرفر هذه العملية حتى تنجح.

3. التحقق من مفتاح

يُرسل POST إلى مسار التحقق الذي تحدده أدناه.
